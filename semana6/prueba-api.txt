Al enviar una petición POST a la ruta:

http://localhost:3000/registro

con el JSON:

{
  "nombre": "Maria",
  "mensaje": "Hola comunidad"
}

el servidor devuelve:

{
  "estado": "Datos recibidos",
  "nombre": "Maria",
  "mensaje": "Hola comunidad"
}

La respuesta confirma que los datos fueron recibidos correctamente y se devuelven en formato JSON.
